## 🔧 Технические детали

### Как работает обучение:
1. Пользователь выбирает архитектуру (YOLOv8/v11) и размер (n/s/m/l/x)
2. При запуске обучения система автоматически скачивает базовую COCO модель
3. COCO модель дообучается на PPE данных пользователя
4. Результат — PPE модель, которая появляется в списке

### Почему COCO модели не нужны в UI:
- Они используются ТОЛЬКО как стартовая точка для Transfer Learning
- Пользователю не нужно их видеть или выбирать
- Скачивание происходит автоматически при обучении
