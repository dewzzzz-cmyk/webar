## 🎯 БЛИЖАЙШИЕ ДЕЙСТВИЯ (ЭТА НЕДЕЛЯ)

### Приоритет 1: Получить рабочую модель

```bash
# Вариант A: Скачать готовую
cd ppe_system_v2
python scripts/download_model.py --model ppe-yolov8n

# Вариант B: Использовать базовую YOLOv8
python scripts/download_model.py --model yolov8n-base
# (будет детектить только person, нарушения добавить позже)
```

### Приоритет 2: Локальный тест

```bash
# Настроить .env
cp .env.example .env
# Отредактировать: JWT_SECRET, пароли

# Запустить без GPU
docker-compose --profile cpu up -d

# Открыть Dashboard
open http://localhost:80
```

### Приоритет 3: Подключить Telegram

```bash
# 1. Создать бота через @BotFather
# 2. Получить chat_id через @userinfobot
# 3. Добавить в .env:
TELEGRAM_BOT_TOKEN=123456:ABC...
TELEGRAM_CHAT_ID=-100123456789
```

## 💰 ОЦЕНКА РЕСУРСОВ

### Минимальные требования (MVP, 3 камеры)

| Ресурс | Спецификация | Стоимость |
|--------|--------------|-----------|
| Сервер | 8 CPU, 16 GB RAM, 256 GB SSD | ~15K ₽/мес (cloud) |
| GPU | RTX 3060 или T4 | ~30K ₽ (покупка) или ~10K/мес |
| Камеры | IP камеры с RTSP | уже есть |
| Разработка | 2-4 недели | - |

### Production (10-20 камер)

| Ресурс | Спецификация | Стоимость |
|--------|--------------|-----------|
| Сервер | 16 CPU, 32 GB RAM, 512 GB SSD | ~30K ₽/мес |
| GPU | RTX 4070 / A4000 | ~80K ₽ (покупка) |
| Резервный сервер | Аналогичный | ~30K ₽/мес |
| Мониторинг | Grafana Cloud | ~5K ₽/мес |
