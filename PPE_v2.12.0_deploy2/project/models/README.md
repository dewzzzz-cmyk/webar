# 📁 Папка Моделей

Здесь хранятся модели для детекции СИЗ.

---

## ⚡ Самый Простой Способ (через Dashboard)

1. Откройте http://localhost:3001
2. Перейдите в **Настройки** → **Модели**
3. Выберите модель и нажмите **"Загрузить"**
4. Нажмите **"Активировать"**

**Готово!** Модель автоматически появится в этой папке.

## 🔧 Ручная Установка

### Базовая YOLO (для теста)

```bash
# YOLOv8 Nano (6 MB)
wget https://github.com/ultralytics/assets/releases/download/v8.1.0/yolov8n.pt \
  -O models/ppe_model.pt
```

### PPE Модель (для детекции СИЗ)

Базовая YOLO видит только общие объекты (person, car).
Для касок и жилетов нужна специализированная модель:

1. Зайдите на https://universe.roboflow.com/roboflow-universe-projects/construction-site-safety
2. Нажмите **Download** → **YOLOv8** → **Download zip**
3. Распакуйте и скопируйте `best.pt` → `models/ppe_model.pt`

---

## 📋 Требования

- Файл модели должен называться `ppe_model.pt`
- Минимальный размер: ~5 MB
- Формат: PyTorch (.pt)
- Архитектура: YOLOv8 или YOLOv11

---

## 🏷️ Классы PPE Модели

Для полноценной детекции нарушений нужны классы:

| Класс | Описание | Действие системы |
|-------|----------|------------------|
| `Hardhat` | Каска надета | ✅ Норма |
| `NO-Hardhat` | Каски нет | 🚨 Нарушение |
| `Safety Vest` | Жилет надет | ✅ Норма |
| `NO-Safety Vest` | Жилета нет | 🚨 Нарушение |
| `Person` | Человек | Для трекинга |
